## Implementation Overview

Phase E1 implements the CFAC Calibration Extraction Service as specified in Part 8.3, 8.4, and 8.5 of the Model Management Workflow Vision document. This service extracts and serializes calibration state after `cfac forecast2` runs, enabling calibration-first model management for capacity factor forecasting.

Defines TypeScript interfaces for CFAC calibration state:

- **MRECCoefficients** - Wind MREC coefficients (vL, vH, tL, tH) per station
- **CFACCalibrationState** - Complete calibration state with:
  - Global bias factors (wind, solar, other)
  - Per-hour solar scale factors (6AM-6PM)

## Storage Format

### Directory Structure

```
models/
└── cfac-calibration/
    ├── calibration_cfac-cal-2026-03-19-143000.json    # Full calibration state
    ├── calibration_cfac-cal-2026-03-15-060000.json
    └── active.json                                     # Reference to active calibration
```

Each calibration is stored as a JSON file with the following structure:

```json

    "end": "2026-03-18"
```

### Active Calibration Reference

The `active.json` file stores a reference to the currently active calibration:

```json
{
  "activeCalibrationId": "cfac-cal-2026-03-19-143000",
  "setAt": "2026-03-19T14:35:00.000Z"
}
```

## Implementation Details

### ID Generation

Calibration IDs follow the format: `cfac-cal-YYYY-MM-DD-HHmmss`
- Example: `cfac-cal-2026-03-19-143000` (March 19, 2026 at 14:30:00)
- Ensures unique, sortable identifiers
- Human-readable timestamps

### Error Handling

- **Directory creation**: Automatically creates `models/cfac-calibration/` on first save
- **File not found**: Returns `null` for missing calibrations (no exceptions)
- **Parse errors**: Logs warnings and skips invalid calibration files
- **Active reference**: Gracefully handles missing `active.json`

### Async Operations

All file operations use `fs.promises` for non-blocking I/O:
- `saveCalibration()` - Writes JSON atomically
- `loadCalibration()` - Reads and parses JSON
- `listCalibrations()` - Scans directory and loads summaries
- `deleteCalibration()` - Removes file and clears active reference if needed
